# Пик по скиллу

Сайт для Dota 2: вводишь код друга из Доты, SteamID64 или ссылку на профиль — и получаешь свой стиль игры, навыки относительно нормы героя, лучшую позицию, ядро героев, кого попробовать и от чего отказаться.

Всё работает в браузере, сервер не нужен. Данные берутся из открытого API [OpenDota](https://docs.opendota.com), база героев — из [odota/dotaconstants](https://github.com/odota/dotaconstants), картинки героев встроены в страницу.

## Как выложить на GitHub Pages

1. Создай на GitHub новый публичный репозиторий, например `pik-po-skillu`.
2. Загрузи в него `index.html` и этот `README.md` (кнопка **Add file → Upload files**).
3. Открой **Settings → Pages**, в **Source** выбери **Deploy from a branch**, ветку `main` и папку `/ (root)`, нажми **Save**.
4. Через минуту сайт будет по адресу `https://<твой-логин>.github.io/pik-po-skillu/`.

## Как считается

- **Позиция в каждой игре** — по полным данным матча (все 10 игроков): перебор 120 расстановок по обычным позициям героев, месту по фарму и линии.
- **Сравнение с соперником и керри** — опыт и золото против игрока на той же позиции, фарм вашего керри против вражеского.
- **Новые герои** — гребневая регрессия по всем героям игрока учит, какие черты героя дают ему плюс к победам; герои, на которых он не играл, оцениваются по тем же чертам, навыкам и похожести на сильных героев.
- **Навыки** — каждая игра сравнивается с распределением OpenDota для того же героя (золото, опыт, добивания, урон, убийства и помощь в минуту, смерти, урон по строениям). 50 — как у среднего игрока на этом герое.
- **Типы героев** — фарм и давление, темп и механика, инициация, поддержка. Процент побед по каждому типу с диапазоном надёжности.
- **Позиция** — процент побед на героях позиции плюс совпадение навыков с задачами позиции.
- **Новые герои** — черты героев (роли, тип атаки, атрибут), на которых игрок выигрывает, плюс сила героя на его ранге.

Бесплатный лимит OpenDota — 60 запросов в минуту; один разбор тратит около 35.
